Version 1.0.1 · ZIP · LZH · PMA · for MSX-DOS2 and Nextor

One pair of tools for every archive format on the MSX

KAGO packs files and whole directory trees into ZIP, LZH and PMA archives; UNKAGO lists and extracts them, including the ones made on modern computers that MSX tools could not open before. Instead of a different tool for each format, one simple pair of tools does it all.

Download KAGO 1.0.1 Read the manual

Free software under the Apache License 2.0. Written entirely in Z80 assembler.

One tool, all three formats

KAGO takes the format from the archive’s name, or from /F:. UNKAGO needs no switch at all: it recognises the format by itself, whatever the file is called.

ZIP .ZIP

The format of every modern computer. Archives made by zip, Windows, macOS or Linux open on the MSX.

deflate, or stored

Two programs, in and out

KAGO the compressor

Packs files, and whole directory trees, into a new archive, or adds them to one that exists.

KAGO [switches] archive files...

UNKAGO the decompressor

Lists an archive, and extracts all of it or only the members you name, here or anywhere else.

UNKAGO [switches] archive [members...]

What they can do

Whole directory trees

Name a directory and everything under it goes in, in ZIP and LZH archives. UNKAGO creates the directories as it extracts.

Archives from modern computers

-lh6- and -lh7- archives from lha, and ZIP files from zip, Windows, macOS or Linux, which the older MSX tools cannot open.

Long filenames

Names that do not fit MSX-DOS’s 8.3 form are shortened the way Windows shortens them: longfilename.txt becomes LONGFI~1.TXT. The same archive always gives the same names.

Adding to an archive

/A adds files to an archive that exists, in all three formats. Files with the same path are replaced; the rest are kept byte for byte.

Safe extraction

UNKAGO checks that everything fits on the disk and in memory before it writes anything, checks every file’s CRC, and never replaces a file unless you ask with /O.

Some members only

Choose what to list or extract with * and ?, or by naming a directory; extract it into another directory with /D:, created if missing.

Dates and attributes kept

Each file’s date and time, and its read-only, hidden and system attributes, go into the archive and come back out.

Any amount of memory

Both tools use the mapper memory that is free when they run. With less than it needs, KAGO packs with a smaller window, or stores, after asking.

Fast on the turbo R

Both run on any MSX2 or later with MSX-DOS2, and are simply faster in the turbo R’s R800 mode.

What you need

  • An MSX2 or later running MSX-DOS2 or Nextor, or an emulator that runs them.
  • A memory mapper, which every MSX that runs MSX-DOS2 has. 128 KB is enough.

The manual describes both tools completely, and the examples show them at work.

Where the name comes from

A kago (籠) is a basket: something woven of bamboo or rattan that you pack things into, and take them out of again. The weave of its strips, over and under, is the mark of this site.
